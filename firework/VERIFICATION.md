## 入力表示の修正と調査結果
旧版で報告された「キー入力で文字が消える」症状は、この検証環境では再現していません。旧版にも入力取消しや編集中の textarea.value の再代入はなく、キャンセルが原因だと断定していません。
改訂版では白文字と WebKit の文字色、本文・装飾・花火の描画順を明示し、Canvas の非同期低遅延描画を外しました。フレームごと・終了時・停止時に、変換行列に依存せず全ピクセルを透明消去します。カーソル位置の計測用要素はサイズ0の隔離要素内に置き、文書のスクロール領域に影響させません。
## ソースとビルド
JavaScript 2ファイルとシェルスクリプトの構文を確認しました。通常の生成と別ディレクトリへの生成が同じ単独 HTML になります。添付仕様書と同梱の spec.md、HTML 内の JSON から復元した仕様書は一致します。
日本語 IME の変換中は演出を保留し、確定を1回にまとめる既存の処理を維持しています。本文へのプログラムからの代入は、初期復元の1か所だけです。6種類の隠しキーは IME 変換中・isComposing・keyCode 229 を除外し、入力欄以外では監視しません。
ターボは8秒間有効で、2.4秒の無入力によるコンボのリセットとは独立しています。実際の強化処理と、停止・非表示時の解除をソース上でも確認しています。
## 維持した既存機能
旧版で確認済みの UTF-8 本文のみの書き出し、仕様書の全文表示と ×・背景・Escape での終了、設定保存、Undo／Redo の標準処理は維持しています。今回、書き出し処理と仕様書表示処理には変更を加えていません。
## 確認範囲
モバイル確認は実ブラウザー内の iframe 寸法を変更したものです。iOS／Android の実端末、実ソフトウェアキーボード、Windows／macOS の実 OS IME、各端末の音響出力は未検証です。VisualViewport の高さ追従を実装していますが、すべての OS・埋め込み先で同じ挙動を保証する実機検証ではありません。
不透明オリジンの sandbox iframe からのダウンロード完了は未確認です。README の埋め込み例は sandbox 属性を付けない構成です。
GitHub リポジトリへの push、GitHub Actions の実行、本番公開は行っていません。既存 workflow に追加するビルドステップを同梱しています。
