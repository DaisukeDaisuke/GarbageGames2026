# 利用規約RPG
「利用規約RPG 企画仕様書 改訂0.5」の全10戦・225通りを実装した静的アプリです。ミュージアムで返金を受けた後、関所・街道・鉄橋・駅を通って自宅へ帰ります。実績マップ、ラブレターの反応、各戦の所要時間を引き継ぎ、結果をXで共有できるボタンを追加しました。ゲーム用APIキーやライブラリCDNは不要です。Xリンクを押したときだけ外部の投稿画面を開きます。
## 配置
ZIP内の `rpg` フォルダーを `Garbage2026` リポジトリの直下へ配置してください。公開先は `/Garbage2026/rpg/` です。`index.html` と `assets/display` を一緒に配置してください。画像は表示用ファイルを相対パスで参照し、音源・脚本・CSS・仕様書はHTML内に含みます。実行時のパスをドメインルートに依存させていません。
## ビルド
配布済みHTMLと表示用画像をそのまま使う場合、ビルドは不要です。ソースを変更した場合は、Node.js 22以上で `bash rpg/build.sh` を実行してください。依存パッケージのインストールは不要です。別の公開ディレクトリへ出力するには `bash rpg/build.sh "$GITHUB_WORKSPACE/_site/rpg"` を実行します。HTMLと表示用画像21枚だけを出力します。
元PNGから圧縮し直す場合は、ImageMagickを用意して `RPG_RECOMPRESS=1 bash rpg/build.sh` を実行します。`magick mogrify` を優先し、ImageMagick 6環境では同等の `mogrify` を使います。画像再圧縮からHTML再生成までこの1本のshで実行できます。
追加した背景5枚の描画から再生成する場合は `RPG_BACKGROUNDS=1 RPG_RECOMPRESS=1 bash rpg/build.sh` を実行します。`tools/make-backgrounds.mjs` がImageMagickのネイティブMVGで描画します。SVG用の外部レンダラーは不要です。既存の背景や生成敵の原本は上書きしません。
## 画像の容量と元データ
背景10枚と会話枠はJPEG、敵10体は透過を保つロスレスWebPです。JPEGは元の寸法と4:4:4の色差情報を保ち、品質99から80,000 bytes以下になるまで調整します。WebPは指定どおり `-quality 100 -define webp:lossless=true -define webp:method=6 -define webp:exact=true` で変換しています。表示用は13,722〜79,867 bytes、21枚合計1,024,615 bytesです。
`assets/*.png` と `art-originals/*.png` は元データとして変更せず保持します。表示用は `assets/display` に分け、ゲームから元PNGを読み込みません。元データを同梱するため、ソースZIP全体が表示画像の合計容量まで小さくなるわけではありません。容量の実測は `IMAGE-COMPRESSION.md` に記載しています。
## GitHub Actions
`deploy-pages.example.yml` は、リポジトリ直下の `.github/workflows/pages.yml` に置くための例です。GitHubのSettings → PagesでSourceをGitHub Actionsにします。既存のPagesワークフローがある場合は、そのワークフローにRPGのビルド手順を追加し、ほかのページと同じ `_site` を1回だけアップロードしてください。例のままではRPGのみが公開対象です。
記事へ埋め込む場合は `<iframe src="/Garbage2026/rpg/" title="利用規約RPG" style="width:100%;height:900px;border:0"></iframe>` を使えます。長い画面はiframe内でスクロールします。
## 操作
各欄から語句をひとつずつ選び、「言う」で確定します。第8戦は対象・項目・値の三欄、それ以外は二欄です。第8戦の「空欄」は選択肢の一つで、未選択とは区別します。同じ語句を再度押すと選択を解除できます。「つづける」、会話枠のタップ、Enterで本文を進めます。キーボードではTabで移動し、EnterまたはSpaceでボタンを選べます。音は初期状態でONです。「冒険をはじめる」の操作で音声再生を有効にし、右上のボタンでON/OFFを切り替えます。ページを開いただけでは音を鳴らしません。
失敗は0ダメージで同じ戦闘へ戻ります。成功は固定100ダメージです。第1戦の「同意」「する」は撃破せず通過し、エンディングが9体撃破になります。それ以外の成功ルートは10体撃破になります。どちらも帰宅するハッピーエンドです。非表示タブ・画面外iframe・実績／仕様書／音素材モーダル表示中はゲーム内時計とダメージ演出が止まり、再生中の音を停止します。
## 実績と時間
右上の「実績マップ」で各戦のことばとつづきの組合せを見られます。第8戦では「攻撃力」「0」「守備力」「空欄」を切り替え、各項目の試行を別々に記録します。「言う」で確定したマスが黄色になり、ホバー・タップ・キーボードフォーカスで台詞を読み返せます。未試行の台詞は表示しません。全開放を目標にする達成率や報酬はありません。
実績はlocalStorageの `garbage2026:terms-rpg:achievements:v1` に保存し、再読込や「もう一度」でも保持します。同じブラウザ・保存先オリジン内の記録で、別の端末には同期しません。ブラウザや埋め込み先が保存を拒否した場合はマップ内に通知し、そのページ内では記録を続けます。
5戦版と同じ保存キーなので、同じ公開URLで更新すると既存の実績を残したまま追加5戦も記録できます。第8戦の旧二語入力の記録は、項目が「攻撃力」の実績へ自動で引き継ぎます。
結果画面では各戦の開始からHPが0になった瞬間までを「N時間N分N秒」で表示します。倒した後に台詞を読む時間と非表示・モーダル中の時間は含みません。スライムを倒さず通った場合は「通過まで」と表示します。再開始でその周回の時間をリセットします。
横長の黒い「X」を押すと、公式Web Intentを新しいタブで開きます。撃破数・言い直し回数・各戦の所要時間合計、ハッシュタグ `#Qiitaアベントカレンダー` と、記事URL `https://qiita.com/DaisukeDaisuke/items/32cf05c0d4255401b1e7` を必ず渡します。投稿の確定はX側で行います。公式資料： https://docs.x.com/x-for-websites/web-intents/overview 。
第2戦に「ラブレター」「抜きます」を追加しました。既存の「脱ぎます」も残し、第2戦の25通りすべてに専用反応を定義しています。チケット購入後に展示が全休止だと分かって返金を求め、王の承認を得るため書庫と面会受付を突破する物語です。ゴーストの3秒待機は通行拒否への異議審査となり、成立すると玉座の間へ進めます。
発言時に剣を振る音が鳴り、1回の発言につき赤いHP数値を1回表示します。不成立・通過は「0 HP」、成功は脚本のダメージ発生時に「−100 HP」です。数値がランダムな方向へ動き、約1.2秒で消えます。HPバーは約0.18秒振動し、その後に赤い残量が約0.6秒かけて減ります。0ダメージでは残量を減らしません。「動きを減らす」設定では飛行・拡大・振動を抑えます。ランダム性は見た目だけに使い、判定・ダメージ・台詞は変更していません。
## 音素材
使用した音素材：OtoLogic (https://otologic.jp/)、CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/)。
音源はクラウドブラウザでOtoLogicの「RPG用セット」から取得しました。剣・命中・ミス・選択・撃破・登場・退場のMP3を `audio` に同梱し、完成HTMLにも埋め込んでいます。音源ファイルは未改変で、ゲーム内で再生音量を調整しています。画面下部にクレジットを常時表示し、「音素材・利用条件」で出典とライセンスを確認できます。詳細は `audio/CREDITS.md`、対応表は `audio/manifest.json` を参照してください。
## 同梱内容
`index.html` はビルド済みのゲームです。`source` は各機能のソース、`assets` は画像21枚のPNGマスターと表示用データ、`art-originals` はPNG原本・背景描画ソース、`art-originals/retakes` は採用前の画像です。`audio` は効果音7種とクレジット、`specification.md` は全台詞を含む仕様書、`ASSET-PROMPTS.json` と `NEW-ASSET-PROMPTS.json` は画像の生成記録です。`ASSET-PREVIEW.jpg` は追加5場面の画像合成見本です。画面下部の「仕様書」で同梱仕様書をアプリ内表示します。
## 検証
`bash rpg/build.sh` の後、`node --test rpg/tests/*.test.mjs` で225通りの結果・台詞・ダメージ・失敗回数・再入力・2種類のエンディング・時計・中断処理・不正タグ拒否に加え、第8戦の三欄のボタン接続と二つの正解（私／攻撃力／0です、君／守備力／0です）から第9戦への進行、実績の保存復元と保存不可時の継続、撃破時間、X共有URL、音声制御・ダメージ演出・全音源の埋め込みを検証します。同じHTTPサーバーで `tests/browser.html` を開くと、実際の語句ボタンを操作するブラウザ検証と幅320・390・600・960pxの確認ができます。この検証用ページはゲーム本体から参照されません。実行環境に関する検証結果は `VERIFICATION.md` を参照してください。
