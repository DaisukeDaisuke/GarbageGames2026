# 任意エンディング
最終話「受話器を置く前に」を最後まで読み終えると、設定に「エンディングを見る」が追加されます。以前の保存でも最終話の既読記録があれば表示されます。
独立したクレジット画面を開き、空の作業台から電話、パソコン、ランダムに選ぶ3種の媒体と3台の端末が順にフェードインします。ロゴ、指定クレジット、写真6枚を縦に自動スクロールします。本文と操作ボタンにはブラウザの既定フォントを使用します。
見出しはH2でコロンなし。中央のクレジット領域を一定の黒背景にし、影にグラデーションやフェードを付けません。自動スクロールは初版の0.8倍（毎秒30.4px）です。パソコンと電話はゲームと同じワールド座標・画像・縮尺で描画します。
右上の「閉じる ×」またはEscapeで、いつでも元のゲーム画面へ戻れます。「一時停止」で停止でき、ホイールやタッチで手動スクロールしたときも停止します。「再生」で続きから進み、最後まで流れると「もう一度見る」に変わります。
再生中はゲームの処理と電話を停止します。納品、所持品、資金、物語、退職、周回の状態をエンディングから変更しません。
## DevTools
コンソールで次の関数を実行すると、そのページを開いている間だけ強制開放して再生します。既読記録や保存データは書き換えません。閉じた後は設定から再度再生できます。再読み込みすると通常の既読判定に戻ります。
```js
unlockKatagiriEnding()
```
## 画像
写真はpoc.zipの収録順にphoto-1.webpからphoto-6.webpへ対応します。元画像の寸法を維持し、quality=100、lossless=true、method=6、exact=trueで変換しています。
ロゴは内蔵画像生成で作成したリテイク版です。生成元PNGはart-source/ending/logo.png、ゲーム用可逆WebPはassets/ending/logo.webpです。
同じロゴをプレイ画面の仮タイトルにも使用します。既存GUIと同じintro.stageが4以上になった時点から表示します。
生成指示の要点：実ゲーム画面の深緑・生成り・琥珀色に合わせた控えめな平面の文字主体ロゴ。表記は「脱獄RTA（物理）」「片桐工房」。明朝風で判読性を確保し、背景透過とする。
## 作業中の権限解除
アプリの導入・削除や設定変更に必要な権限は、その作業が残っている間は復旧電話の対象から除外します。最初から開放されている権限も同じです。その権限に依存する作業をすべて終え、返却条件が施錠なら、その時点で復帰案内を出します。不要な権限の解除と禁止履歴は従来どおり判定し、同じ案内の電話は初回のみ、以降は手動相談です。納品検品の条件は変更しません。
