# 脱獄RTA（物理）v3.1

Canvas 2Dで動く、架空の端末を直す机上ゲーム。100件の依頼、100機種・各8方向の端末画像、30種類の媒体、機材・技能・任意退職と再就職を実装しています。

## 配置とビルド

このZIPは `DaisukeDaisuke/GarbageGames2026` への追加用です。ZIPの `jailbreakGame/` とルートの `build.sh` をリポジトリに重ねて配置してください。他のゲームはZIPに含めていません。

Node.js 20以上とBashが必要です。npm installや外部素材の取得は不要です。

```sh
bash jailbreakGame/build.sh
# 指定した公開ディレクトリへ出力する場合
bash jailbreakGame/build.sh /absolute/path/site/jailbreakGame
```

既定の出力先は `jailbreakGame/dist/`。この中身を `/GarbageGames2026/jailbreakGame/` に配置できます。相対URLで画像・音源・データを読みます。配信用JPEG・WebP・音源・生成済みデータはすべて同梱しています。容量を減らすため、同じ素材を複製した `dist/` はZIPに入れず、ビルドで生成します。ES Modulesとfetchを使うため、ファイルを直接開かずHTTPサーバーで配信してください。

ルート `build.sh` は既存4作品の処理を維持し、このゲームのビルドを追加しています。ほかの作品のソースを含む元リポジトリで実行してください。

## 遊び方

- 最初は電話のみ。受話器を取り、説明を進めるとPCと初期媒体が現れます。
- 初回は上司の会話に続いて最初の契約を自動表示します。成功条件の表と短い案内を見て受注します。以後はPCをクリックしてメールから選びます。
- 最初の端末が届くと電話が鳴り、KomaOSの管理者制限とUSBを使う理由、実行・取り出し・検品までを説明します。
- 机に届いた端末を回し、形状が合う穴へ媒体をドラッグします。クリックで媒体を選び、穴をクリックしても差せます。
- 端末本体をクリックすると直接操作画面へ接近します。権限の解除・アプリ・設定・再施錠は独立した工程です。
- 右の常駐メニューから媒体や機材を購入します。パネルは横から開きます。
- 検品は無料。返却条件を満たして返すと報酬を受け取ります。
- 最初の2台は研修です。その後は通常5件の納品で一周を修了します。再就職後に研修は繰り返しません。上の信用ランクでも、慣れたKomaOSの依頼を選べます。
- 人事画面から任意退職できます。次の新人は当周の対象報酬の50%を初期資金へ加算し、技能を引き継ぎます。
- 媒体・機材の買い取り技能は各2個、上位技能で各4個まで工房長から引き取れます。開始時の信用の紹介状はD→C→B→Aの順に各10SPで取得し、次の就職時の信用ランクを上げます。技能がなくても納品による通常の昇格はできます。通常納品は5件で、慣れた下位ランクの依頼も1件として数えます。同じ依頼の繰り返し練習は数えません。
- 初周は研修2台を含む実納品3〜6件目に工房の謎に関する4話が届き、通常5件の完了時には再就職の利点を電話で説明します。2周目以降は再就職のお祝いの後、追加の実納品2件ごとに第5〜10話が届きます。途中で契約を終えても未読の続きから再開します。一度聞いた物語はパソコンの「記録 → 会話・技能」で読み返せます。信用ランクの昇格電話や操作案内は別枠です。

机上の物はドラッグで配置できます。左右矢印キーか端末下の矢印で8方向へ回転、Escapeで工房へ戻ります。一覧はホイールまたはドラッグでスクロール。TabとEnterでも操作できます。進行はブラウザに自動保存し、設定から書出し・読込みができます。

## 内容と検証

`content/` が編集用データ、`data/` が生成データ、`src/` がゲーム、`assets/` が配信素材、画像生成PNGと制作指示は別配布の `optional-source/jailbreakGame/art-source/` です。内部IDと表示名の対応は `docs/INTERNAL_NAME_MAP.md` と `data/display_names.json` にあります。ゲーム画面は内部IDを表示名へ変換します。

ビルド時に100案件・199解法の契約検品、保存・料金・禁止履歴・周回・計画機能などを自動検証します。検証範囲と未確認事項は `docs/IMPLEMENTATION_NOTES.md` を参照してください。

効果音はOtoLogic、CC BY 4.0。ゲーム内設定と `docs/THIRD_PARTY_NOTICES.md` にクレジット、出典、ライセンスを記載しています。

追加ソースは `jailbreakGame-optional-source-1of4.tar.gz` から `4of4.tar.gz` までの4ファイルです。それぞれ同じ場所へ展開すると `optional-source/` にまとまります。必要な場合だけ、その `art-source/` を `jailbreakGame/art-source/` へコピーしてください。通常の起動・ビルドに追加ソースは不要です。

画像の再変換は任意です。Sharpを利用できる環境で `node tools/prepare-art.mjs` を実行します。通常のビルドにSharpは不要です。
